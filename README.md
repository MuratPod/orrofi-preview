# OrroFi — превью брендбука v5

Статичный сайт для GitHub Pages: обзор брендбука, страницы 1–7, логотипы и иконки для скачивания, примеры применения и раздел о помощнике Orro (`orro/index.html`).

- Все пути относительные; сборка не нужна. Откройте `index.html` или включите Pages на ветке с этой папкой в корне.
- `.nojekyll` отключает обработку Jekyll.
- Шрифт Nunito — SIL OFL 1.1. QR на экранах — пример с фиктивным паролем `EJEMPLO-0000`.
